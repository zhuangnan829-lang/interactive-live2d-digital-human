## Licence interpretation for this project

The ArtStation Marketplace EULA for Stock Assets allows a licensee to copy, use, modify, adapt, publicly display, transmit, and create derivative works from the product as part of a Work. The Extended Commercial tier allows any number of commercial Works without sales or view limits. This supports Blender conversion to GLB and use inside a commercial or non-commercial interactive application after purchase.

The EULA also prohibits distributing the Product outside a Work or making it available for others to use, download, or copy. A web application necessarily transfers render assets to the browser; serving a converted GLB as an obvious standalone public download could therefore create an avoidable licence risk. Before public deployment, retain the receipt and applicable EULA snapshot and obtain seller confirmation that browser delivery of the converted model as a non-reusable part of the application is permitted. Do not publish the source archives, editable Blender/FBX files, textures, or a reusable standalone GLB.
