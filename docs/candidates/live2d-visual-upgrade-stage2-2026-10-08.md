日期：2026-10-08

## 当前结论

Haru 继续作为已经通过完整技术验证的最终备用方案。第二阶段暂未替换正式人物，也未购买任何商业模型。

商业候选中，以下三款明显比普通 VTuber 模型更接近“在线课程 AI 讲师”：

1. **Gen.101A スーツ女性（SOL / nizima）**：当前综合首选，女性西装、商务/公司职员定位，法人使用记录，13 个表情和 8 个动作。
2. **できる！おねえさん（sakura）**：视觉上最接近参考图 1 的保守商务女性讲师，带西装/马甲/衬衫切换、微笑、困惑、愤怒、鞠躬和左右指示动作。
3. **窓口みどり**：授权用途与本项目最匹配，明确允许公司演示、商品宣传、数字接待、应用、游戏和视频；视觉比 Haru 更偏接待人员，但画风仍较卡通。

三款均为付费下载。公开商品页不足以完成压缩包级五类文件验证，也不能代替 Cubism Web SDK 实测；在购买或卖家提供文件清单前，状态只能是 **采购候选**，不能标记为“验证通过”。

## 采购前必须获得的确认

向 Gen.101A、Sakura 或窓口みどり卖家发送购买前询问，要求书面确认：

1. 下载包实际包含 `.moc3`、`.model3.json`、至少一个 `.motion3.json`、`.physics3.json` 和 `.exp3.json`。
2. `.model3.json` 中存在 `EyeBlink` 和 `LipSync` 组，或提供对应眼睛开闭与嘴巴开合参数 ID。
3. 存在可映射到 `ParamMouthOpenY` 的连续嘴巴开合参数，而不只是音量触发图片/部件切换。
4. 眉毛、嘴角、眼睛和头部 XYZ 参数可供 Smile / Serious / Doubt 使用。
5. 许可允许将模型嵌入本项目 Web 页面进行课程演示、作品展示和企业培训；浏览器会向最终用户传输运行时模型文件这一实现方式也在许可范围内。
6. 是否需要额外的 Live2D SDK 发布许可、法人许可、署名或域名/项目申报。

第 5 项尤其重要：很多商品页允许视频和直播，但 Web SDK 会把模型运行时资源发送到浏览器，可能被视为不同于“视频展示”的分发方式。没有卖家书面确认前不得上线。

## Izumi 实测

来源：https://www.live2d.com/en/learn/sample/izumi/  
官方包 SHA-256：`39ED8F111DA39F731DD079680D918CD4AEDC23A99C63E39535C9F045A129CBDE`

仅替换模型目录和参数 ID 资源映射后，保持 Haru 验证页的 UI、TTS 请求、音频分析、表情状态和停止逻辑不变。

- SDK：Cubism SDK for Web 5-r.5。
- Chrome：154 / Windows 10 / 1920×1080 / WebGL2 / Intel UHD D3D11。
- 时长：60,010 ms（READY 后计时）。
- 平均：142.64 FPS。
- 最低一秒样本：96.41 FPS。
- 中文口型最大值：0.9999991。
- 播报采样 `PARAM_MOUTH_OPEN_Y`：0.7498。
- 停止后嘴型：0。
- Smile / Serious / Doubt：已通过 Izumi 的旧式 `PARAM_*` 参数 ID 映射驱动眉、眼、嘴和头部。

判定：**技术完整通过，视觉淘汰。** 用户已明确认为该模型不美观；其脸型、旧式画风和红色便装也不具备企业课程讲师形象。后续不再围绕 Izumi 调整构图、服装或参数，不进入正式替换候选。

证据：`evidence/2026-10-08-live2d-izumi-stage2/`。
